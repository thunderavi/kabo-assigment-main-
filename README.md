# ⚡ KABO - Frontend (React + Vite)

Welcome to the **KABO** frontend project, built with **React** and powered by **Vite** for blazing-fast development. ✨

---

## 📦 Local Installation (Laptop)

> Make sure you have [Node.js](https://nodejs.org/) and [Git](https://git-scm.com/) installed.

### 🖥️ Steps to run on your laptop:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/kabo.git
cd kabo

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev
